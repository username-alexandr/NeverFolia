# R8 isolated generation-stage tools

**Experiment only. Never use an existing/live world.** Normal production builds do
not install the candidate. A matching datapack fingerprint alone does not authorize
a native generator change; do not remove worldgen locks.

Use Java 25 and the exact compatible full NeverFolia runtime. Build the complete
Nether pack from its five pinned source ZIPs and verified supplemental inputs.
Compile `NeverNetherStageProbe.java` against that runtime, include `plugin.yml`, and
package it only as a diagnostic plugin. The runner requires a new directory, binds
only to 127.0.0.1, records all classpath file hashes, rejects JVM option injection,
freezes simulation before the selected chunks, and stops normally after the probe.

The optional candidate is applied AFTER the normal production transformer chain in
a separate fresh generated Folia build:

```sh
python3 scripts/apply-never-nether-experiment-r8.py /fresh/Folia \
  --acknowledge-experimental-worldgen
```

Exact source/anchor checks precede writes, and reapplication is idempotent. The CI
exports a small compiled class overlay, not a complete installable server. No
third-party assets or worlds are generated by this compile job.

The measured plan is seed 7270913, chunks X=-216..-212 and Z=-46..-42, ascending X
then Z. Its JSON has the form `{"seed":7270913,"chunks":[[-216,-46],[-216,-45]]}`;
include ALL 25 pairs to reproduce the measurement, not just these two examples.
The review bundle contains the exact plan. Review the Minecraft EULA before passing
the runner's explicit acknowledgement.

```sh
python3 qa/nevernether-r8/run-stage-probe.py \
  --java /java25/bin/java --runtime-dir /exact/runtime \
  --pack /matching/NeverNether.zip --qa-plugin /compiled/stage-probe.jar \
  --new-directory /disposable/forward --plan /plans/forest25.json --accept-eula

# Repeat into another NEW directory with --reverse, then compare:
python3 scripts/compare-never-nether-stages-r8.py \
  --left /disposable/forward --right /disposable/reverse \
  --output /reports/reverse.json
```

Also repeat the forward order in a third new directory and compare using
`--relation same`. Compare orders WITHIN one runtime profile. A baseline-to-candidate
runtime difference is not an order test. Validate every stopped startup log using
`validate-never-nether-startup-r5.py`; a completed probe alone is not clean loading.

CARVERS snapshots must be exact CARVERS ProtoChunks. First LIGHT callbacks may
already expose SPAWN but must still be ProtoChunks before FULL. Later settled
snapshots can be automatically promoted to FULL, requiring an owning-thread check.
There are no explicit FULL requests. Status changes during capture invalidate a run.
Every observation checks frozen/not-stepping simulation, coordinates, hashes and
coverage. Failed, forced-stop, partial or mismatched-input runs cannot pass.

Every block state at Y=-128..895 is compared, including fluids, air variants, plants
and roof space. The state dictionary is exact; no problematic blocks are normalized
away. This does not replace persisted-world, biome, block-entity, loot, multi-seed or
structure-playability acceptance. `release_ready` stays false even for zero residual.

Candidate caveats: the plant-transparent view is not immutable terrain or a plant
provenance map. Structure vegetation and later non-plant writes still require
special handling. Arbitration can change forest shape; quality, attachments, support
geometry and cost remain unaccepted. The remaining differences are not waived.
