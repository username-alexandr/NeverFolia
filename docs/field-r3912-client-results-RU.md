# R39.12 — клиентское отображение зачарований

Дата: 28 сентября 2026 года.
Статус: готовое клиентское дополнение для ручного теста. Это не новое серверное ядро и не приёмка всех багов NeverFolia.

## Выполненный результат

Созданы два файла: самостоятельный ресурс-пак с переводами для обычного Minecraft 26.2 и клиентский Fabric-мод с фильтром служебных книг и теми же переводами.

Ресурс-пак меняет только названия. Swift Soar отображается как «Стремительный полёт», Wither Coated — «Иссушающее покрытие», Bug Enchant — «Служебное зачарование» в русской локали. В английской локали служебная запись получает пояснение Internal controller (not a survival enchantment). Всего включены 18 ключей: 17 игровых названий и одна общая подпись служебных записей.

Мод использует существующие собственные CreativeBookMixin и EnchantmentVisibility. Фильтр применяется к созданию списков зачарованных книг в creative-категориях и поиске; исключает технические записи Nova, но не удаляет их из реестра и не изменяет предметы, уже находящиеся в инвентаре. ID, игровые эффекты, функции, лут и экипировка не меняются. Английские названия Swift Soar/Wither Coated не трактуются как повреждение регистрации.

Отдельный ресурс-пак НЕ скрывает книги; для фильтра нужен клиентский Fabric-мод. Серверный R39.11, его водная логика, датапаки и пользовательские миры в этой итерации не менялись. Никакой server.jar в выдаваемом архиве нет. Два существующих варианта R39.11 с разными бинарными хешами не заменяются друг другом.

## Установка

Распаковать внешний архив дополнения. Для перевода без модов внутренний NeverLand-Enchantments-RU-26.2-R39.12.zip поместить в resourcepacks именно используемого клиента Minecraft 26.2, не распаковывая его; включить выше других переводов и выбрать русский язык.

Для скрытия служебных книг: Minecraft 26.2, Fabric Loader 0.19.3 или новее, Java 25. Поместить NeverLand-Enchantment-UI-Fabric-26.2-R39.12.jar в клиентскую папку mods. Предыдущую версию того же neverland_enchantment_ui заменить, не устанавливать обе. Отдельный Fabric API модулю не требуется. Перезапустить игру. Мод уже содержит переводы, поэтому второй ресурс-пак необязателен.

НЕ помещать эти файлы в server/plugins или world/datapacks. Сервер R39.11 не заменять, мир не пересоздавать ради этой правки. Проверить ингредиенты и поиск книг: технические книги должны быть исключены только из списков, игровые книги должны остаться. Если мод мешает запуску клиента, убрать только новый JAR и сохранить клиентский logs/latest.log; сервер откатывать не требуется.

## Сохранённые неудачи и ограничения

Первый run 36389638387 завершился ошибкой KeyError: resource в сборщике: использовалась старая схема version.json. Исправлен разбор resource_major/resource_minor и оставлена строгая проверка 88.0. Также исправлен сбор диагностики, чтобы cp не прекращался на __pycache__. Первоначальная неудача не считается успешным тестом; старые логи и артефакты сохранены GitHub.

Локальные container/Python в этой попытке возвращали ClientError, включая независимую попытку проверить скачанные ZIP. Компиляция, выполнение тестов и упаковка сделаны именно в GitHub Actions, не локально в чате. Доступ к компьютеру пользователя не использовался. Скачаны точные артефакты завершённого запуска; новая локальная побайтовая проверка не заявляется.

Лёд, водяные карманы, данжи, мобы и оставшиеся ресурсы не менялись в R39.12. Черновой PR24 не слит. Эта поставка — завершённый этап клиентского исправления с явно указанной ручной проверкой Mixin/рендеринга, не исправление всех багов проекта.
