# NeverFolia FIELD-R38 — кандидат, не автоматическое обновление сервера

База: PR #12, ветка wip/neveroverworld-r37-continuation, Folia 26.2 / Java 25.

## Изменения

- Очистка растительности R13/R15 и остатков растительности/снега после затопления теперь подчиняется границе естественного дна колонки. Контакт с водой сам по себе больше не создаёт новый источник под навесом. Существующее состояние воды сохраняется.
- Превращение утопленника в наездника выполняется одной конечной операцией на потоке владельца. Используется ссылка на созданного наутилуса, не ближайшая чужая сущность. При отмене посадки удаляется только новая сущность; предмет-контроллер сохраняется до успеха.
- Опциональный наблюдатель сохраняет воду до LIGHT и сравнивает после полной цепочки, включая очистку экологии. На обычном сервере отключён. Для QA: -Dneverfolia.waterAuditDirectory=/absolute/empty/directory.
- Сохранены исправления пулов, чужих NBT-атрибутов и креплений R37; синтетические острова под данжами по-прежнему отключены.

## Проверки

CI собирает настоящий Java25 сервер. Проверяются функции помощников, точное создание наездников и отмены событий; реальные обычные игроки активируют два неизменённых trial-конфига датапака. Водный тест охватывает 48 чанков проблемного seed -4651369264513492755, два порядка загрузки и перезапуск.

Истина о результате — r38-live-qa.json, поле pass. Один успешный build не означает успешную проверку игры. Неудачные результаты и логи не удаляются. Координаты камеры из старых скриншотов служат диагностикой, а не выдуманным эталоном воздуха: исходное состояние сравнивается непосредственно перед нашей обработкой.

## Установка на отдельный стенд

Java 25, server.jar и оба zip из одного комплекта. server.jar — самодостаточный bundler, проверенный командами java -jar; ему не требуется отдельно подменять библиотеки. Не устанавливать QA-плагины на рабочий сервер. Создать новый тестовый мир; не удалять мир игроков. Старые уже записанные квадратные острова и вода этим исправлением автоматически не переписываются.

После резервного копирования использовать обычную остановку сервера, не /reload. Принятие Minecraft EULA выполняется владельцем стенда. Значения offline-mode и loopback из автоматического QA не являются рекомендацией для рабочего сервера.

## Границы

Два нормальных trial-конфига не означают проверку всех боссов, их умений, ominous-режимов и всех seed. Полный глобальный квестовый runtime D&T не включается вслепую; запрещённые общие команды Folia остаются отключены. PR не сливается автоматически, рабочий сервер и сохранения не меняются.
