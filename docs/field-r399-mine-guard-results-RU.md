## Исправление

До правки protectedCell() возвращал false при null в chunk.neverOverworldDryMineMaskR12, даже если постоянные данные чанка содержали границы шахты. Теперь отсутствие временного кэша переключает проверку на прежний readBoxes(), сохраняющий валидацию ВСЕХ записанных частей. При существующем кэше остаётся быстрый путь.

Проверяются отдельные BoundingBox частей, не общий прямоугольник шахты. Сохраняется отсечение текущим чанком и диапазоном paint(): -511..128. Нижний слой -512 не включается. Метод не загружает соседние чанки, не меняет блоки, постоянные данные или кэш.

Late-stage установщик: scripts/apply-never-overworld-dry-mine-r399.py. Он проверяет точный Git blob исходника 119af8898ba1edbd654ae6edf43ea5f67c043b23, отказывается менять неизвестную версию, поддерживает повторный запуск и сохраняет резервную копию при установке. Исторический helper в native/neveroverworld/field-r12 оставлен прежним, чтобы не разрушить ранние контракты материализации. Преобразование применяется к изолированной копии сборщиком R399. Основная Gradle-цепочка автоматически не изменена; для неё установщик предназначен как отдельный поздний этап после R38/R396.
