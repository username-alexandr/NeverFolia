## Запуск

Распаковать только в новую пустую папку. Нужна Java 25. После самостоятельного принятия Minecraft EULA изменить eula=false на eula=true. Windows: start.bat; Linux: bash start.sh. Оба скрипта используют jvm.args, где включён -Dneverfolia.r399OceanClosure=true. Старый флаг r395 не включает этот класс.

Подключение: localhost:25611 или IP тестовой машины:25611. Конфигурация слушает все интерфейсы; доступ ограничить тестовой сетью. Online-mode и whitelist включены, RCON выключен. После Done выполнить в консоли whitelist add НИК и op НИК. Остановка: stop. Память 1–4 ГБ в jvm.args. Windows-скрипт подготовлен, но на Windows не исполнен.
