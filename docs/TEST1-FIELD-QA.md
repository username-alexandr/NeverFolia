## Regressions found in first real field test

The first manual TEST1 run exposed the following regressions. Every item below is now either runtime-gated, datapack-gated, or explicitly included in repeat field QA.

| Regression | Expected TEST1-R1 behavior | Automated coverage |
| --- | --- | --- |
| `/profiler` rejected XYZ form | `/profiler world X Y Z seconds radius` starts and finishes | runtime smoke |
| giant vertical canyons | no pathological hundreds-of-block vertical open columns | cave topology gate |
| rectangular/box-like cave extrusion | no long identical partial horizontal masks | cave topology gate |
| ores immediately below flood surface | no resource ores in `Y=65..135` sterile band | datapack + final-NBT field audit |
| trees under water | no submerged logs/leaves in sampled Y=128 flooded columns | final-NBT field audit |
| sugar cane/lily pads left under water | old flora removed and shoreline flora relocated | final-NBT field audit + manual shoreline check |
| rails under water | no flooded rails in sampled flood columns; mineshafts are deep-only | final-NBT field audit + placement policy |
| Trial Chambers too high | starts constrained to `Y=-320..-96` | datapack field audit |
| mineshafts did not use deep range | deep-only target `Y=-448..-112` | runtime placement patch + manual locate check |
| vanilla stronghold / End Portal dungeon remained | vanilla stronghold disabled | datapack + runtime policy |
| villages under water | dry-land starts rejected if conservative footprint falls below dry Y=129 surface | runtime placement policy + manual locate check |
| Woodland Mansion under water | dry-land start rejected using conservative footprint | runtime placement policy + manual locate check |
| swamp hut behavior | hut retained as flood-adapted structure and re-anchored to `Y>=129` | runtime placement policy + manual locate check |

## Frozen automatic thresholds

These thresholds are intentionally looser than the accepted `2f680ee` baseline so normal world variation has headroom while the original pathological shapes still fail.

- maximum vertical open run: `<=160` blocks
- maximum identical partial layer-mask run: `<=32` blocks
- flooded tree blocks in sampled flood columns: `0`
- flooded rail blocks in sampled flood columns: `0`
- flooded sugar cane / lily pad blocks in sampled flood columns: `0`
- resource ore blocks in `Y=65..135`: `0`

Accepted `2f680ee` topology baseline:

- FULL chunks scanned: `326`
- max vertical open run: `124`
- max identical partial mask run: `18`
- chunks containing columns `>=192`: `0`
- chunks containing columns `>=256`: `0`
- mean open fraction: `0.035807`

## Manual repeat test

Use a completely fresh world. Do not reuse chunks generated by the first TEST1 package.

1. Install the frozen `2f680ee` Paperclip JAR and both final datapack ZIPs before first world generation.
2. Start with no NeverLand production plugins. Confirm `/version` and `/datapack list enabled`.
3. Run `/profiler world <x> <y> <z> 10 100` in a loaded area and confirm it starts instead of printing usage/error.
4. Fly across fresh Overworld terrain at the Y=128 flood boundary. Look specifically for vertical terrain walls, repeating rectangular cave cuts, drowned tree remnants, underwater rails and vegetation.
5. Inspect fresh stone around `Y=65..135`; normal resource ore veins should not appear in this transition band.
6. Check deep terrain around `Y=-100`, `-200`, `-300`, `-400`, and near the bottom. Confirm caves remain varied and do not form continuous surface-to-bottom shafts.
7. Locate/generate Trial Chambers and verify the structure is inside approximately `Y=-320..-96`.
8. Locate/generate mineshafts and verify they remain in the deep profile rather than returning to the flooded surface domain.
9. Confirm vanilla stronghold/End Portal progression is absent.
10. Locate several villages and Woodland Mansions around flooded regions. They must not start submerged or extend materially into the flooded lowland.
11. Locate a swamp hut. It should remain a valid swamp feature but sit at the new flooded waterline rather than at the old drowned ground level.
12. Enter NeverNether through a normal portal, inspect fresh chunks, and return through the portal.

When reporting a failure, capture: exact coordinates, F3 Y-level, structure ID if applicable, screenshot, and the relevant server-log interval. For worldgen visual defects, preserve the seed and do not regenerate the affected chunk until diagnosis is complete.
